# 별의 밝기 탐구 시뮬레이션

중학교 2학년 과학 Ⅷ. 별과 우주 › 1. 별 › **별의 밝기는 어떻게 나타낼 수 있을까?** (교과서 280~283쪽) 수업용 인터랙티브 시뮬레이션입니다.

## 실행 방법

`index.html` 파일을 내려받아 더블클릭하면 크롬·엣지·웨일 등 브라우저에서 바로 열립니다.
인터넷 연결이나 별도 프로그램 설치가 필요 없습니다. 주소 끝에 `#1`~`#5`를 붙이면 해당 활동이 바로 열립니다.

## 활동 구성

| 활동 | 내용 |
|---|---|
| ① 거리와 밝기 | 거리 슬라이더(1~5배), 빛 알갱이 144개가 퍼지는 모습, 거리-밝기 그래프·기록 표, 교과서 실험값(638·158·71·40 lx) 비교 |
| ② 등급과 밝기 | −2~9등급 수직선, 등급 사이 약 2.5배, 빛 알갱이 상자(1등급 100개 vs 6등급 1개), 등급별 밝기 막대그래프 |
| ③ 밝기가 같은 두 별 | 실제 밝기가 같은 두 별의 거리를 바꾸며 겉보기 밝기·겉보기 등급 비교 |
| ④ 절대 등급 (10 pc) | 시리우스·미르잠 등을 10 pc로 옮기는 애니메이션, 겉보기 등급과 절대 등급 비교 그래프 |
| ⑤ 개념 확인 문제 | 객관식·O/X 12문항(즉시 피드백·해설) + 서술형 1문항, 핵심 정리 |

화면 오른쪽 위 **[교사용 안내]**에 교과서 연결, 수업 운영 예시, 수치 근거, 지도 시 유의점이 정리되어 있습니다.

# 별의 색과 표면 온도 탐구 시뮬레이션

Ⅷ-1-03. 별의 색이 다양하게 나타나는 까닭은 무엇일까 (교과서 284~285쪽) 수업용 시뮬레이션입니다. 파일: `star-color.html` (실행 방법은 위와 같습니다. 주소 끝에 `#1`~`#4`).

| 활동 | 내용 |
|---|---|
| ① 달궈지는 열선의 색 | 전압 슬라이더로 열선의 색 변화(붉은색 → 주황 → 노랑 → 흰색) 관찰·기록 |
| ② 별의 색과 표면 온도 | 표면 온도 슬라이더(K), 실제 별 버튼, 파란 빛·붉은 빛 비교 그래프, 분광형 O·B·A·F·G·K·M, 태양 온도 낮추기 |
| ③ 색으로 온도 비교하기 | 두 별의 색만 보고 더 뜨거운 별 고르기, 교과서 별 자료 막대그래프, ‘붉은색 별이 더 뜨겁다’ 오개념 |
| ④ 개념 확인 문제 | 객관식·O/X 10문항 + 서술형 1문항 |
