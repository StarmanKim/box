# 별의 밝기 탐구 시뮬레이션

중학교 2학년 과학 Ⅷ. 별과 우주 › 1. 별 › **별의 밝기는 어떻게 나타낼 수 있을까?** (교과서 280~283쪽) 수업용 인터랙티브 시뮬레이션입니다.

## 실행 방법

`index.html` 파일을 내려받아 더블클릭하면 크롬·엣지·웨일 등 브라우저에서 바로 열립니다.
인터넷 연결이나 별도 프로그램 설치가 필요 없습니다. 주소 끝에 `#1`~`#5`를 붙이면 해당 활동이 바로 열립니다.

## 활동 구성

| 활동 | 내용 |
|---|---|
| ① 거리와 밝기 | 거리 슬라이더(1~5배), 빛 알갱이 144개가 퍼지는 모습, 거리-밝기 그래프·기록 표, 교과서 실험값(638·158·71·40 lx) 비교 |
| ② 등급과 밝기 | −2~9등급 수직선, 등급 사이 약 2.5배, 빛 알갱이 상자(1등급 100개 vs 6등급 1개), 등급별 밝기 막대그래프 |
| ③ 밝기가 같은 두 별 | 실제 밝기가 같은 두 별의 거리를 바꾸며 겉보기 밝기·겉보기 등급 비교 |
| ④ 절대 등급 (10 pc) | 시리우스·미르잠 등을 10 pc로 옮기는 애니메이션, 겉보기 등급과 절대 등급 비교 그래프 |
| ⑤ 개념 확인 문제 | 객관식·O/X 12문항(즉시 피드백·해설) + 서술형 1문항, 핵심 정리 |

화면 오른쪽 위 **[교사용 안내]**에 교과서 연결, 수업 운영 예시, 수치 근거, 지도 시 유의점이 정리되어 있습니다.

# 별의 색과 표면 온도 탐구 시뮬레이션

Ⅷ-1-03. 별의 색이 다양하게 나타나는 까닭은 무엇일까 (교과서 284~285쪽) 수업용 시뮬레이션입니다. 파일: `star-color.html` (실행 방법은 위와 같습니다. 주소 끝에 `#1`~`#4`).

| 활동 | 내용 |
|---|---|
| ① 달궈지는 열선의 색 | 전압 슬라이더로 열선의 색 변화(붉은색 → 주황 → 노랑 → 흰색) 관찰·기록 |
| ② 별의 색과 표면 온도 | 표면 온도 슬라이더(K), 실제 별 버튼, 파란 빛·붉은 빛 비교 그래프, 분광형 O·B·A·F·G·K·M, 태양 온도 낮추기 |
| ③ 색으로 온도 비교하기 | 두 별의 색만 보고 더 뜨거운 별 고르기, 교과서 별 자료 막대그래프, ‘붉은색 별이 더 뜨겁다’ 오개념 |
| ④ 개념 확인 문제 | 객관식·O/X 10문항 + 서술형 1문항 |

# 2026 생기부 마스터 (중학교)

「2026학년도 학교생활기록부 기재요령 중학교」(17개 시도교육청, 2026.2.)를 반영한 학교생활기록부 작성 도우미입니다. 폴더: `school-record/` (GitHub Pages 주소 끝에 `/school-record/`)

| 기능 | 내용 |
|---|---|
| 명렬표 | 엑셀·나이스에서 복사한 표 붙여넣기, .xlsx·.csv 파일 불러오기(학년·반·번호·이름 열 자동 인식) |
| 작성 영역 | 과목별 세부능력 및 특기사항(500자), 자율·자치활동(3학년은 자율활동, 500자), 동아리활동(500자), 진로활동(500자), 행동특성 및 종합의견(300자) |
| 학년도·학년별 자동 전환 | 2026학년도 중1·중2 = 2022 개정, 중3 = 2015 개정 / 2027학년도 선택 시 중3도 2022 개정 (기재요령 부칙) |
| 성취기준·성취수준 | 2022 개정 중학교 10개 교과(국어·사회·역사·도덕·수학·과학·영어·체육·음악·미술) 성취기준 432개와 성취기준별 성취수준(A~E/A~C)을 「2022 개정 교육과정에 따른 중학교 ○○ 성취수준」 원문 그대로 내장(`school-record/std/`). 그 밖의 과목은 붙여넣어 추가 |
| 학교 창체 계획 | 학교 「창의적 체험활동 연간 운영 계획」 CSV를 불러와 자율·자치/진로 특기사항 작성 시 학년별 활동을 날짜·시수와 함께 선택, 관찰 기록 추가, 정량 기록 문장 생성(기재요령 p.77), 반 전체 적용 |
| 관찰 기록 | 활동·장면 / 관찰한 행동 / 변화·성장을 여러 번 누가기록, 특장점 키워드 선택, 임원(전교·학년·학급+재임기간), 희망분야, 동아리 유형 |
| 문구 만들기 | 외부 전송 없이 앱 안에서 관찰 기록만 조합(‘~함’ 문체 변환, 학생별 구조 변화, 목표 분량 맞춤). 기록에 없는 내용은 만들지 않음 |
| 검수 | 나이스 Byte(한글 3·영문/숫자/엔터 1), 기재 금지 표현(대회·어학시험·논문·특허·대학명·부모 직업 등, 근거 쪽수 표시), 명사형 종결·특수문자/번호(p.30), 영문 사용(p.28), PAPS 1등급만(p.103), 복사로 섞인 문자, 학생 이름 포함, 다른 학생과 같은 문장 |
| 학사 일정·임원 | 학기 시작·종료일, 학년말, 졸업일 설정 → 자율·자치/동아리 임원 재임기간 자동 채우기(p.78), 창체 계획에서 개학일·졸업일 찾기 |
| 학급 점검 | 모든 학생 확정(창체·행특), 진로희망 입력, 임원 재임기간, 교과 세특 입력 비율(학교 기준 설정), 기재 불가·형식 문제를 학급 단위로 요약 |
| 확정 | 기재요령 p.19 유의사항(직접 관찰, 과장 금지, 학생 작성 금지, AI 생성물 그대로 입력 금지) 체크리스트 후 확정 |
| AI 윤문 프롬프트 | 학생 이름·반·번호를 가린 프롬프트 복사 (AI 결과는 그대로 입력 불가 안내 포함) |
| 내보내기 | 학급 전체 보기에서 확정 문구 일괄 복사·CSV·TXT·인쇄 |
| 자료 보관 | 이 브라우저에만 저장(서버 전송 없음), 백업 파일(.json) 저장·불러오기, 오프라인 사용·홈 화면 추가 지원 |

이 도구는 작성 보조용입니다. 최종 판단은 기재요령 원문과 소속 학교 학업성적관리규정을 따르세요.
